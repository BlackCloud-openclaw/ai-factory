## 一、Character Change 评分标准修正

### 原则
Character Change 测量的是**角色决策模型的改变**，而非行为是否已执行。

### 评分标准

| 分数 | 定义 | 判定依据 |
| :--- | :--- | :--- |
| 1 | 无变化 | 角色对自我、他人、世界的认知未发生任何变化 |
| 2 | 产生怀疑 | 开始质疑原有认知，但尚未形成新的判断框架 |
| 3 | 认知模型改变 | 世界观、自我认知、价值判断发生重构。**即使尚未采取行动，只要决策逻辑已变，即为 3 分** |
| 4 | 行为准则改变 | 长期行为模式发生可观察的改变（如：不再信任某人、改变修炼方式） |
| 5 | 身份认同改变 | 角色对自身根本定义发生不可逆转变（弟子→叛徒、凡人→修仙者、正道→魔道） |

### 边界案例裁决

| 案例 | 裁决 | 理由 |
| :--- | :--- | :--- |
| 林逸发现师父一直在骗他，章节结束，未采取任何行动 | **3 分** | 认知模型已重构，决策逻辑改变。根据修正定义，不需要等到行动执行。 |
| 林逸说了“备马”表明选择守城，但尚未出发 | **3 分** | 已做出选择，决策模型从“寻找两全其美”变为“接受牺牲”。行为承诺足以证明改变。 |
| 林逸仅仅感到“有点不对劲”，但说不清哪里不对 | **2 分** | 仅产生怀疑，尚未形成新的认知判断。 |

## 二、Dialogue Richness 与 Interaction 的区分

### 核心区别
- **Dialogue Richness**：测的是**语言层面的博弈**（潜台词、欺骗、试探、说服）。即使双方行为照旧，只要语言有张力，即可高分。
- **Interaction**：测的是**行为导致的改变**。一方必须因另一方的行为而发生**非惯性状态变化**。

### 判断流程
在标注 Dialogue 和 Interaction 时，按以下顺序自问：

1. **这段对话有潜台词吗？有语言博弈吗？**
   - 是 → Dialogue 至少 3 分
   - 否 → Dialogue ≤ 2 分

2. **对话/行为是否导致对方状态发生了改变？**
   - 对方改变了决策、情绪、行动计划 → Interaction 至少 3 分
   - 对方只是回应但没有实质变化 → Interaction ≤ 2 分

### 边界案例裁决

| 案例 | 裁决 | 理由 |
| :--- | :--- | :--- |
| 林逸与二叔对峙，林逸转身离开，二叔没有叫住他 | Dialogue = 4.5，Interaction = 3.5 | 对话博弈极强（有证据、有沉默施压），但行为影响有限（关系虽破裂但尚未质变，二叔未反击）。 |
| 两人争吵五页，但最终什么也没改变 | Dialogue 可能很高（3-4），Interaction ≤ 2 | 有语言博弈但无行为后果。 |
| 苏清雪把剑丢给林逸，转身离开，林逸握紧剑柄 | Dialogue 可能很低（1），Interaction ≥ 3 | 几乎没有对话，但行为导致林逸状态改变。 |

## 三、Narrative Tension 的客观化定义

### 原则
Narrative Tension 测量的是**未来状态的不确定性（Expected Future Uncertainty）**，而非“有没有悬念词”。

### 判断流程
标注 Narrative Tension 时，按以下步骤思考：

1. **场景结束时，未来还有多少种可能的发展路径？**
   - 几乎确定（1-2 种）→ 低分
   - 中等不确定性（3-5 种）→ 中等分数
   - 完全不可预测（大量分支）→ 高分

2. **这种不确定性来自哪里？**
   - 未回答的问题（“玉简里写的什么？”）
   - 即将到来的危机（“敌人正在逼近”）
   - 未确认的身份或关系（“苏清雪到底是谁？”）

### 边界案例裁决

| 案例 | 裁决 | 理由 |
| :--- | :--- | :--- |
| 林逸发现父母死于宗门谋杀，信笺中提及“剑阁底层”有答案 | **5 分** | 未来完全不可预测：谁是敌人？剑阁底层有什么？长老会为什么要这样做？大量分支。 |
| 林逸找到宝物，安全返回 | **1 分** | 未来确定。任务完成，没有未解决的问题。 |
| 林逸发现玉佩有裂纹，但未说明原因 | **2-3 分** | 有轻微未解细节，但影响有限。 |

## 四、Goal Advancement 的反刷分原则

### 原则
Goal Advancement 测量的是**目标状态空间是否被重新定义**，而非完成了多少步骤。

### 判断流程
标注 Goal Advancement 时，问自己：

1. **这个信息/事件是否改变了主角对“目标”的理解？**
   - 否 → ≤ 2 分
   - 是 → 至少 3 分

2. **如果删掉这个步骤，目标状态是否仍然相同？**
   - 如果相同，说明推进有限
   - 如果不同，说明有实质推进

### 边界案例裁决

| 案例 | 裁决 | 理由 |
| :--- | :--- | :--- |
| 获得地图 → 获得钥匙 → 获得船票（连续三章） | 每章 **1-2 分** | 步骤在累加，但目标状态“需要到达剑阁”未发生变化。 |
| 获得地图，但发现地图是假的，必须重新寻找路线 | **4 分** | 目标路径发生根本性变化。 |
| 林逸发现父母死于宗门谋杀，目标从“修炼变强”变为“调查长老会” | **5 分** | 目标本身被替换，状态空间完全重定义。 |

## 五、多维度高分共存原则

### 原则
**一个场景允许在多个维度上同时获得高分**。这不算重叠错误，而是同一场景在不同层面的戏剧效果。

### 示例
在 GOLD_REV（发现父母死亡真相）中：
- **Narrative Tension = 5**：未来完全不可预测
- **Goal Advancement = 5**：目标从“变强”变为“复仇”
- **Character Change = 3**：认知模型已重构，但尚未执行行动

三个维度同时高分，合理。

## 六、标注者培训流程

所有新标注者在进入正式标注前，必须完成以下步骤：

1. **阅读** `narrative_kpi_spec_v1.md` 和本文档
2. **独立标注** GOLD_DIA、GOLD_CHO、GOLD_REV 三个样本
3. **计算偏差**：
   - 若任一维度与 Gold Standard 偏差 > ±1.0 → 需重新培训，不得进入正式标注
   - 若所有维度偏差 ≤ ±0.5 → 可直接进入标注
   - 若介于两者之间 → 需讨论差异原因后决定
