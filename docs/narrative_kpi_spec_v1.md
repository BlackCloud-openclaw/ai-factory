# Narrative KPI Specification v1.0

**状态**：定稿
**生效日期**：2026-06-18
**关联文档**：`narrative_annotation_guide.md`、`narrative_annotation_guide_addendum.md`

---

## 1. 顶层定义（核心公式）

**Narrative Value = √(Reader Engagement × Story Progression)**

- **Reader Engagement**：读者在阅读过程中感受到的卷入程度（情感、好奇、紧张）。
- **Story Progression**：故事世界状态发生的不可逆、有意义的变化。

**设计原则**：任何一边趋向于零，整体价值都趋向于零。五章纯粹的会议纪要（高推进，低卷入）和五章无脑战斗（高卷入，低推进）都不会得高分。

---

## 2. Reader Engagement（读者卷入）

### 2.1 Dialogue Richness（对话丰富度）

- **定义**：对话是否构成语言层面的博弈（潜台词、欺骗、试探、说服）。
- **核心**：测"语言在做什么"，而非"有多少字"。
- **区分**：与 Interaction 的区别在于——Dialogue 聚焦"嘴上的博弈"，即使行为未改变，语言本身有张力即可高分。

**评分标准**：

| 分数 | 定义 |
| :--- | :--- |
| 1 | 纯信息交换（"找到线索了。""好，出发。"） |
| 2 | 有观点分歧但无交锋（"走东边。""西边更安全。"） |
| 3 | 有明确立场冲突（"你不能去。""我必须去。"） |
| 4 | 冲突中带有个性/潜台词（"你以为我不知道你去过禁地？"） |
| 5 | 对话改变角色关系或行动（对话后，两人决定分道扬镳） |

---

### 2.2 Interaction（角色互动）

- **定义**：角色的**行为**是否导致另一个角色的状态、选择或情绪发生**非惯性改变**。
- **核心**：测"行为产生的实质影响"，与 Dialogue 区分。
- **区分**：Dialogue 聚焦"嘴上的博弈"；Interaction 聚焦"行为导致的改变"（递剑、救人、背叛、离开）。

**评分标准**：

| 分数 | 定义 |
| :--- | :--- |
| 1 | 同处一场景但无相互影响（林逸修炼，苏清雪看书） |
| 2 | 单向观察或简单回应（林逸看了一眼，苏清雪点头） |
| 3 | 双向言语/行动回应（林逸建议，苏清雪反驳并给出理由） |
| 4 | 一方迫使另一方做出选择（"交出玉佩，或死。"） |
| 5 | 互动导致角色状态/关系发生质变（苏清雪救林逸后，林逸重新评估她） |

---

### 2.3 Conflict（冲突）

- **定义**：任何**阻止角色立即获得其想要事物**的力量。
- **范围**：外部对手（战斗）、系统规则（禁令）、内部恐惧（心魔）均包含。
- **核心**：冲突 = 阻碍。角色想要的东西越难拿到，冲突越强。

**判分规则（删除测试）**：
> 如果删除该元素，角色是否马上就能拿到想要的东西？如果是 → Conflict 高分（至少 4 分）。

**评分标准**：

| 分数 | 定义 |
| :--- | :--- |
| 1 | 无阻碍，目标顺利达成 |
| 2 | 轻微外部阻力，轻易克服（简单机关） |
| 3 | 明确的外部对手或规则（守护傀儡、宗门禁令） |
| 4 | 叠加的内部/外部冲突（必须战斗，但对手是故人） |
| 5 | 多重压迫（外部 + 内部 + 巨大代价） |

---

### 2.4 Pressure（角色压力）

- **定义**：角色在"想要 X" + "被阻碍 Y" + "承担代价 Z"时承受的张力强度。
- **核心**：Pressure ≠ Suffering（受苦≠压力）。压力来自**代价的不可逆性**与**时间的紧迫性**。

**判分规则（删除测试）**：
> 如果删除该元素，角色即使失败是否也无关紧要？如果是 → Pressure 低分。

**评分标准**：

| 分数 | 定义 |
| :--- | :--- |
| 1 | 无紧迫感，无代价（悠闲探索） |
| 2 | 有时间限制（"三日内赶到"） |
| 3 | 时间限制 + 资源不足（"三日内，灵力只剩三成"） |
| 4 | 时间 + 资源 + 道德/情感代价（"三日内，否则师父被处决"） |
| 5 | 多重不可逆选择（"救师父必须放弃妹妹"） |

---

### 2.5 Narrative Tension（叙事张力）

- **定义**：场景结束时，读者心中存留的**未解决问题、未引爆危机、或未确认的身份/关系**。
- **核心**：测"读者想不想翻页"，而非"作者有没有埋坑"。
- **客观化定义**：**Expected Future Uncertainty**——未来还有多少种可能的发展路径？

**评分标准**：

| 分数 | 定义 |
| :--- | :--- |
| 1 | 一切问题已解决，无后续钩子 |
| 2 | 有轻微未解细节（玉佩有裂纹，但未说明原因） |
| 3 | 一个明确未回答的问题（"玉简里只有一句话：不要相信苏清雪"） |
| 4 | 叠加的未解问题和即将到来的危机（警告 + 苏清雪就在门外） |
| 5 | 读者产生强烈预测欲，未来完全不可预测 |

---

## 3. Story Progression（故事推进）

### 3.1 Relationship Movement（关系移动）

- **定义**：角色之间关系**拓扑结构**是否发生不可逆的质变。
- **核心**：测"陌生人→盟友"或"盟友→仇敌"，而非"好感度 70→75"。

**评分标准**：

| 分数 | 定义 |
| :--- | :--- |
| 1 | 关系无变化 |
| 2 | 数值微调，关系性质不变（70→75） |
| 3 | 关系性质发生单次转变（陌生人→同盟） |
| 4 | 多重关系同时质变（与苏清雪和解，但与二叔决裂） |
| 5 | 关系质变导致故事方向改变（盟友→仇敌，剧情转向） |

---

### 3.2 Goal Advancement（目标推进）

- **定义**：主角的核心目标或子目标**状态空间**是否发生重要变化。
- **核心**：测"状态转换"，而非"任务步骤计数"。
- **反刷分原则**：完成的步骤数不直接等于推进。只有当目标状态发生变化时，才记高分。

**评分标准**：

| 分数 | 定义 |
| :--- | :--- |
| 1 | 目标状态无变化 |
| 2 | 获得新信息，但目标路径未变 |
| 3 | 目标路径发生变化（绕路、改道） |
| 4 | 目标优先级发生变化 |
| 5 | 目标本身被替换或否定（发现目标是陷阱） |

---

### 3.3 Character Change（角色变化）

- **定义**：角色的**决策模型**是否发生改变。
- **核心**：**不看行为是否执行，看内在转化**——世界观、自我认知、价值判断是否发生重构。
- **修正说明**：本定义区别于早期版本。无需等待角色执行行动，只要决策逻辑已变，即为有效变化。

**评分标准**：

| 分数 | 定义 | 判定依据 |
| :--- | :--- | :--- |
| 1 | 无变化 | 角色状态与场景开始时一致 |
| 2 | 产生怀疑 | 开始质疑原有认知，但尚未形成新判断 |
| 3 | 认知模型改变 | 世界观、自我认知、价值判断发生重构。**即使尚未行动，只要决策逻辑已变，即为 3 分** |
| 4 | 行为准则改变 | 长期行为模式发生可观察的改变 |
| 5 | 身份认同改变 | 角色对自身根本定义发生不可逆转变（弟子→叛徒，正道→魔道） |

---

## 4. 计算与汇总

### 4.1 各层得分

- **Engagement** = (Dialogue + Interaction + Conflict + Pressure + Tension) / 5
- **Progression** = (Relationship + Goal + Character) / 3

### 4.2 最终分数

- **Narrative Value** = √(Engagement × Progression)

*注：所有单项评分均为 1-5 连续值（允许 0.5 分增量）。*
