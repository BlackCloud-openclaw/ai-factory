ADR-014: Projection Dead Letter Queue

状态：已接受

背景：
某些事件可能导致投影器异常（如数据损坏、格式错误）。如果无限重试，会阻塞后续事件。

决策：

    投影 worker 捕获异常后，将事件写入 projection_dead_letters 表，记录错误信息和堆栈。

    重试最多 3 次，仍失败则标记为 skipped，继续处理后续事件。

    提供管理 API 查询死信事件，支持手动重试或修复。

后果：

    一个坏事件不会阻塞整本小说的投影。

    需要运维监控死信队列。

    保留故障现场数据，便于排查。
