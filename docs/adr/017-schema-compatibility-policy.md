# ADR-017: Schema Compatibility Policy

## 状态
已接受

## 背景
事件溯源系统中，事件 schema 会随需求演化。需要明确的兼容性规则，防止破坏历史数据可重放性。

## 决策
### 允许的变更
- 添加可选字段（新字段应允许为 null 或缺失）
- 扩展枚举值（仅添加新值，不删除或重排序）
- 添加新的事件类型
- 在 upcaster 中填充新字段的默认值

### 禁止的变更
- 重命名字段（必须通过 upcaster 创建别名）
- 删除必需字段（必须先标记 deprecated，至少一个版本后移除）
- 改变字段的语义或类型
- 复用已废弃的事件类型名称
- 改变已有枚举值的含义

### 删除流程
1. 标记字段为 `deprecated: true`，代码中忽略该字段但保留读取
2. 至少保留一个完整版本周期（如 2 个主要 release）
3. 在 upcaster 中移除该字段的写入
4. 最终删除列

## 后果
- 历史事件可安全重放
- 开发者需要更谨慎地设计 schema 变更
- 需要维护 upcaster 版本链
