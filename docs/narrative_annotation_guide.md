# Narrative Annotation Guide v1.0

**状态**：定稿
**生效日期**：2026-06-18
**关联文档**：`narrative_kpi_spec_v1.md`、`narrative_annotation_guide_addendum.md`

---

## 1. 目标

确保至少 3 位标注者对同一场景给出的分数高度相关（ICC > 0.85）。

---

## 2. 标注流程

### Step 1：通读（第一遍）
完整阅读场景文本，不做任何标记。建立整体印象。

### Step 2：精读（第二遍）
边读边标记以下内容：

| 标记 | 内容 |
| :--- | :--- |
| **谁想要什么** | 每个角色的显性/隐性目标 |
| **阻碍是什么** | 阻止角色获得目标的力量（外部/内部/规则） |
| **结尾留了什么** | 场景结束时未解决的问题、未确认的信息 |

### Step 3：逐维度打分
按 `narrative_kpi_spec_v1.md` 中定义的 8 个维度逐一打分（1-5，允许 0.5 分增量）。

**建议顺序**：
1. Conflict → 2. Pressure → 3. Dialogue → 4. Interaction → 5. Narrative Tension → 6. Relationship Movement → 7. Goal Advancement → 8. Character Change

### Step 4：Overall Drama
给出一个综合评分（1-10），代表"这个场景整体有多好看"。

---

## 3. 各维度标注要点

### 3.1 Dialogue Richness
- **看**：语言是否有潜台词？是否有博弈？
- **不看**：对话字数多少。
- **问自己**：这段对话换个说法会损失什么？如果损失很大 → 高分。

### 3.2 Interaction
- **看**：行为是否导致对方状态改变。
- **不看**：是否有很多人在说话。
- **问自己**：如果没有这个行为，对方会不一样吗？如果会 → 高分。

### 3.3 Conflict
- **看**：阻碍是否真实存在。
- **不看**：是否有打架。
- **问自己**：删除这个阻碍，角色能否马上得到他想要的？如果是 → 高分。

### 3.4 Pressure
- **看**：代价有多大？时间有多紧？
- **不看**：角色是否在受苦。
- **问自己**：如果失败，角色会失去什么不可逆的东西？失去越多 → 越高分。

### 3.5 Narrative Tension
- **看**：未来还有多少种可能。
- **不看**：是否出现"悬念"两个字。
- **问自己**：读完后我多想翻到下一页？越想翻 → 越高分。

### 3.6 Relationship Movement
- **看**：关系性质是否改变。
- **不看**：好感度数字。
- **问自己**：如果重读这一章，他们的相处方式会不同吗？如果是 → 高分。

### 3.7 Goal Advancement
- **看**：目标是否被重新定义。
- **不看**：完成了多少步骤。
- **问自己**：删除这段内容，主角对目标的理解会不同吗？如果会 → 高分。

### 3.8 Character Change
- **看**：决策模型是否改变。
- **不看**：是否采取了行动。
- **问自己**：如果他回到场景开头，他会做出同样的选择吗？如果不会 → 高分。

## 4. 边界案例判定（常见误区）

### 误判 1：给所有"有对话"的场景打高 Dialogue
- **场景**：两人闲聊五页，内容不涉及核心矛盾，关系无变化。
- **判定**：Dialogue Richness 低（2 分）。虽然有对话，但无博弈。

### 误判 2：给所有"有危险"的场景打高 Pressure
- **场景**：龙套角色在战斗中阵亡。
- **判定**：Pressure 低（1 分）。删除该事件，读者毫无感觉。

### 误判 3：给所有"拿到宝物"打高 Goal Advancement
- **场景**：直接走进山洞，捡起宝物。
- **判定**：Goal Advancement 低（1 分）。无阻碍，无状态变化。

### 误判 4：因角色未行动而给 Character Change 打低分
- **场景**：林逸发现师父一直在骗他，章节结束，未采取行动。
- **判定**：Character Change = 3（认知模型已改变，决策逻辑已变）。
- **规则**：**无需等待行动执行，只看决策模型是否重构。**

### 误判 5：认为多个维度不能同时高分
- **场景**：身份揭露场景（发现父母死亡真相）。
- **判定**：Narrative Tension（5）、Goal Advancement（5）、Character Change（3）可同时高分。
- **规则**：**允许高分共存**，这是同一场景在不同层面的戏剧效果。

## 5. 黄金标准参考

新标注者在正式标注前，必须标注以下三个黄金样本。偏差标准：

- 任一维度偏差 > ±1.0 → 需重新培训
- 所有维度偏差 ≤ ±0.5 → 可直接进入标注
- 介于两者之间 → 讨论差异后决定

### Gold Standard 分数表

| 维度 | GOLD_DIA | GOLD_CHO | GOLD_REV |
| :--- | :--- | :--- | :--- |
| Dialogue Richness | 4.5 | 1.0 | 1.0 |
| Interaction | 3.5 | 2.0 | 1.0 |
| Conflict | 2.5 | 5.0 | 2.5 |
| Pressure | 2.0 | 5.0 | 4.0 |
| Narrative Tension | 3.5 | 4.0 | 5.0 |
| Relationship Movement | 3.5 | 1.0 | 2.5 |
| Goal Advancement | 1.0 | 3.5 | 5.0 |
| Character Change | 3.0 | 3.0 | 3.0 |
| Overall Drama | 6.0 | 8.0 | 7.5 |

*关于 Character Change：GOLD_CHO 中林逸已做出选择（"备马"），决策模型改变 → 3 分。*
